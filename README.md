# CST438Project3


A full-stack trip planning application built with Spring Boot (Kotlin), React Native (Expo), and PostgreSQL. 

## Quick Start

This repository contains everything you need to run the application locally. We use Docker Compose to simplify the setup process.

1. **Clone the repository:** `[git clone https://github.com/your-username/CST438Project3.git](https://github.com/CST438-S2G3-Project3/CST438Project3.git)`
2. For the .env set up you can ask one of use for the necessary passwords
3. To run the API in one terminal window run 'cd api' then './run.sh' or you can use 'docker compose up -d --build' to build it through docker desktop
4. To run the app in another terminal window type 'cd app' then 'npm install' and finally 'npx expo start'
