## Context

`The team has decided to host our API on Render while having it packaged by Docker. We believe that this choice will be the easiest and best way to host our API.`

## Options considered

| Option | Pros | Cons |
|---|---|---|
| `Render + Docker` |`Free, Simple, already familiar` | `Waiting for spinup` |
| `Railway` | `auto-deploy through GitHub, Provides environment variables and private networking` | `Could cost money for scope of project, limited included usage and resources` |

## Decision

`We will host our API using Render and run it using Docker.`

## Consequences

- **Good:** `Many of us are already aware of how to use Render and Docker and what is needed to create a product with it`
- **Bad:** `We will have to make sure we spin up the project whenever we want to test routes.`
