## Context

`The team has decided that the database should be hosted using Supabase as it provides a simple and free way of hosing a database. The team looked at other options like Neon but decided that Supabase would be the best option for this project.`

## Options considered

| Option | Pros | Cons |
|---|---|---|
| `Supabase` |`Free, Simple, already familiar` | `Space limitiation` |
| `Neon` | `More space, Free, more Postgres focused` | `Usage limits, unfamiliar` |

## Decision

`We will create and host our database on Supabase.`

## Consequences

What becomes easier, what becomes harder, and what the team now has to live with or revisit.

- **Good:** `Many of us are already aware of how to use Supabase and what is needed to create a product with it.`
- **Bad:** `We might run into space issues while using the free tier.`
